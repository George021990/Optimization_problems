# Optimization of Transport Costs for a Greenhouse Complex

**Статус:** прототип / исследовательская реализация  
**Область:** дискретная оптимизация, логистика, целочисленное программирование (MIP)  
**Стек:** Python, Pyomo, GLPK  

## Описание задачи

Модель решает задачу выбора оптимального транспорта и распределения заказов для тепличного комбината. Цель — минимизировать суммарные затраты на аренду транспорта при соблюдении:

- ограничений по грузоподъёмности транспорта;
- требований по времени доставки;
- лимитов на количество доступных транспортных средств.

Задача относится к классу смешанных целочисленных задач линейного программирования (MILP) с булевыми переменными для моделирования условий «если–то» (активность транспорта, выбор типа машины).

## Что реализовано

- **Математическая модель** с явным описанием переменных, целевой функции и системы ограничений.
- **Учёт времени доставки**: булевы переменные определяют, успевает ли транспорт доставить груз в требуемое время.
- **Выбор оптимального типа транспорта**: для каждого клиента выбирается тип транспорта, минимизирующий стоимость доставки при выполнении ограничений.
- **Реализация на Pyomo** с использованием солвера GLPK.
- **Воспроизводимость**: входные данные вынесены в отдельный блок, результаты выводятся в читаемом виде.

## Входные данные

| Параметр | Описание | Пример |
| --- | --- | --- |
| `H` | Вместимость транспорта (кг) | `[15, 22]` |
| `D` | Спрос клиентов (кг) | `[26, 19, 28]` |
| `P` | Лимит доступного транспорта | `[10, 10]` |
| `t0` | Требуемое время доставки (дни) | `[12, 10, 16]` |
| `t11`, `t12` | Фактическое время доставки для типов транспорта | `[6,15,6]`, `[6,6,20]` |
| `G` | Стоимость перевозки (руб/км) | `[145, 160]` |
| `R` | Расстояния до клиентов (км) | `[56, 67, 48]` |

## Математическая модель (кратко)

**Целевая функция:** минимизация суммарной стоимости эксплуатации транспорта:


**Основные ограничения:**

1. **Покрытие спроса:** суммарная вместимость задействованного транспорта должна покрывать спрос клиента (с учётом булевой переменной выполнения заказа).
2. **Лимиты на транспорт:** количество машин каждого типа не превышает доступного парка.
3. **Временные окна:** транспорт может быть задействован только если успевает доставить груз вовремя (моделируется через булевы индикаторы).
4. **Логика выбора стоимости:** для каждого маршрута выбирается один тип транспорта с минимальной стоимостью доставки, удовлетворяющий ограничениям.

Полный вывод модели и обоснование ограничений см. в файле `model_description.pdf` (или в комментариях к коду).

## Как запустить

### Требования

- Python 3.8+
- Pyomo: `pip install pyomo`
- Солвер GLPK (`glpsol`) в PATH (на Windows: скачать с winglpk.sourceforge.net)

### Запуск

```bash
cd Quality_optimization
python transport_optimization.py
```
