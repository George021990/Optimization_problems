# Оптимизация качества продукции (биуровневая модель PAO)

Модель оптимизации качества продукции на основе лидер-последовательной
(биуровневой / двухуровневой) задачи оптимизации, реализованная на Python
с использованием библиотек **Pyomo** и **PAO** (Pyomo Automation Objects).
Решается методом релаксации фиксированной точки (FA — Fixed-Point Algorithm)
из модуля `pao.pyomo`.

## Решаемая задача

Требуется определить оптимальный уровень качества продукции `x` с учётом
реакции четырёх взаимосвязанных функциональных подсистем производства:

| Подсистема | Переменная | Функция | Смысл |
|---|---|---|---|
| Качество продукции (верхний уровень) | `x` | `Q(x, y, z, t) → min` | Итоговый показатель качества |
| Управление поставщиками | `y` | `F1(x, y) → min` | Оптимальный выбор поставщиков |
| Затраты на качество | `z` | `F2(x, z) → min` | Оптимизация затрат на качество |
| Технологичность | `t` | `F3(x, t) → min` | Оптимальные технологические операции |

Все переменные непрерывные и неотрицательные. Лидер (верхний уровень)
выбирает `x`, а последователи (нижний уровень) — подчинённые модели `L`, `L1`,
`L2` — оптимизируют свои целевые функции при фиксированном `x`.

## Математическая постановка

```
Q(x, y, z, t) = x - 2y + 2z + 3t  →  min            (лидер)

F1(x, y) = x + 2y                  →  min            (последователь L, переменная y)
F2(x, z) = (1 - x) + 2z            →  min            (последователь L1, переменная z)
F3(x, t) = 2 - 2t + t              →  min            (последователь L2, переменная t)

Ограничения лидера:      A·(x, y, z, t)ᵀ ≤ C   (15 ограничений)
Ограничения F1:          A1·(x, y)ᵀ ≤ C1       (20 ограничений)
Ограничения F2:          A2·(x, z)ᵀ ≤ C2       (6 ограничений)
Ограничения F3:          A3·(x, t)ᵀ ≤ C3       (20 ограничений)
```

Матрицы коэффициентов `MM`, `MM1`, `MM2`, `MM3` и правые части `C`, `C1`,
`C2`, `C3` формируются из введённых пользователем данных.

## Входные данные

Программа запрашивает с клавиатуры:

1. **Качество продукции** — количество активных блоков (строк) и значения
   показателей качества для каждого компонента изделия (15 компонентов × 8
   показателей).
2. **Поставщики** — количество активных блоков и значения показателей
   качества для каждого поставщика (20 поставщиков × 3 показателя).
3. **Затраты на качество** — количество активных блоков и значения
   показателей для категорий затрат (6 категорий × 3 показателя).
4. **Технологичность** — количество активных блоков и значения показателей
   для технологических операций (20 операций × 4 показателя).

Каждая строка матрицы вводится как числа, разделённые пробелами.

### Обработка данных

- Неактивные строки матриц (после указанного числа активных блоков) заполняются
  нулями.
- По каждой строке считается отношение суммы показателей к числу ненулевых
  позиций (коэффициент `C` правой части ограничения).
- Если `0 < C < 1`, строка считается «стимулирующим» признаком: коэффициенты
  строки и правой части меняют знак на противоположный (минимум «затрат»
  превращается в максимум «эффекта»).

## Установка зависимостей

```bash
pip install pyomo pao numpy
```

> Для работы алгоритма FA из PAO требуется сторонний решатель линейного
> программирования (например, `glpk` или `cbc`). См. документацию PAO:
> https://pao.readthedocs.io

Задача решателя указывается в конце файла:

```python
solver = Solver('pao.pyomo.FA')
results = solver.solve(M, tee=True)
```

## Запуск

```bash
python model.py
```

Следуйте подсказкам ввода. По завершении решения результаты (значения
переменных и целевых функций) выводятся в консоль.

## Примечания

- Модель решает биуровневую задачу с одним лидером и тремя последователями
  (модели `SubModel` с фиксированной переменной `x`).
- Для полноценного использования алгоритма FA модель нижнего уровня должна
  оставаться выпуклой (линейной), что здесь выполнено.
- Значение `N3` (число активных блоков) должно быть ≤ количества строк в
  соответствующих матрицах (15, 20, 6, 20).
